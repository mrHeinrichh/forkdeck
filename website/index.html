A FEW THINGS TO KNOW

From download
to first commit.

How do I install ForkDeck?

On macOS, open the downloaded disk image and drag ForkDeck to Applications. On Windows, run the installer and follow the setup steps.

Install Git first, then open a local repository in ForkDeck. GitHub CLI is optional and is used by the GitHub authentication repair feature.

Why does my computer show a security warning?

This community release is not Apple notarized or signed with a Windows publisher certificate. macOS may ask you to allow ForkDeck in System Settings → Privacy & Security. Windows SmartScreen may show an unknown publisher warning.

Only proceed if you trust this release. You can compare the download with the published SHA-256 checksums before opening it.

Which Mac download should I choose?

Open the Apple menu → About This Mac. If it shows an Apple M-series chip, choose Apple Silicon. If it shows an Intel processor, choose Intel.

Where does my work live?

Your repositories stay on your computer. ForkDeck saves its repository list and commit profiles in your operating system’s application data folder. Fetching, pulling, and pushing connect to the remotes you have configured.

There is no ForkDeck account or subscription. Your existing Git credentials still handle access to your repositories.
